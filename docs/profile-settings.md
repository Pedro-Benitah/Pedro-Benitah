## Próxima evidência de engenharia de dados

Evolua um projeto existente com entregas verificáveis: fonte pública com licença e dicionário de dados; ingestão repetível; modelo SQL; verificações de esquema, nulos e duplicidades; consultas documentadas; API ou visualização de consumo. Publique a arquitetura e um exemplo reproduzível somente após implementar e validar o fluxo.

Mantenha estudos corporativos fora do portfólio. Um futuro estudo de caso profissional depende de autorização e revisão de confidencialidade; não reutilize nomes internos, dados de clientes ou diagramas proprietários.

## Manutenção visual

- O README usa Markdown nativo e seções verticais, evitando tabelas largas nos destaques do perfil.
- O banner fica em `assets/`, com duas versões SVG selecionadas por `<picture>` e `prefers-color-scheme`. O fallback é a versão clara.
- Não depende de contadores de visitas, cartões externos de estatísticas, tokens ou workflows agendados.
- Ao alterar o banner, confira texto alternativo, contraste e leitura em tela estreita nos dois temas.
- Atualize cargo atual, conclusão do curso e links quando houver mudanças verificáveis.
